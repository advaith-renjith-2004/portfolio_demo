# Advaith Renjith — Minimalistic Web Portfolio

A clean, responsive, and minimalistic web portfolio built using pure HTML5 and Vanilla CSS. Designed for a college assignment at Mar Baselios College of Engineering and Technology (Autonomous).

## Features
- **Minimalist Glassmorphic Design**: Deep dark-chocolate palette with warm sand accents, custom borders, and blur filters.
- **Structured Layout Sections**: 
  - **Home (Hero)**: Brief intro, S7 B.Tech badge, and key call-to-actions.
  - **About Me**: Brief bio, general details, and metric stats box.
  - **Education**: Timeline grids showing qualification scores (B.Tech, 12th CBSE, 10th CISCE).
  - **Technical Skills**: Badge grids divided into languages and framework capabilities.
  - **Experience**: Timeline detailing internship periods and responsibilities.
  - **Projects**: Cards describing custom software builds.
  - **Co-Curriculars & Achievements**: Displays magazine editing, placement coordination roles, and athletic rewards.
  - **Contact**: Quick-link details and a functional mockup message form.
- **Pure HTML & CSS**: Built without React, Next.js, TypeScript, Tailwind, or complex build engines.
- **Responsive Layout**: Designed to adapt fluidly to desktop, tablet, and mobile viewport devices.

## Running Locally
No complex installation required:
1. Open the repository folder.
2. Double-click [index.html](index.html) (or drag it into any modern web browser) to launch the static site locally.
